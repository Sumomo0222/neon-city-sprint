# 霓虹城市冲刺 · NEON CITY SPRINT

打开链接即玩的轻量**伪 3D 霓虹跑酷网页小游戏**：你在深夜的霓虹都市中自动向前冲刺，通过左右切换车道和跳跃躲避路障、货车，沿途收集能量币，冲出最远距离并争取 S 级评价。

整个场景（城市天际线、广告牌、路灯、道路、角色、障碍、能量币）全部使用 **HTML / CSS / 内联 SVG** 程序化绘制，**零外部图片素材、零依赖、零构建**。

## 本地打开

方式一（最简单）：直接用浏览器打开 `dist/index.html` 即可，无需任何服务器。

方式二（可选，本地静态预览）：

```bash
cd neon-city-runner/dist
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 操作方式

| 动作 | 桌面端 | 手机端 |
| --- | --- | --- |
| 左移 | `←` 或 `A` | 左下角 `◀` 按钮 / 屏幕左滑 |
| 右移 | `→` 或 `D` | 左下角 `▶` 按钮 / 屏幕右滑 |
| 跳跃 | `空格` / `↑` / `W` | 右下角 `▲` 按钮 / 屏幕上滑或点按 |
| 开始 / 重开 | `回车` 或 `空格` | 点击按钮 |

- 三条车道（左 / 中 / 右），障碍从远处迎面而来；
- 橙黑条纹**路障**可以跳过，货车 / 厢车必须变道躲避；
- 金色**能量币**：跑到所在车道即可收集，跳上路障上方的币弧有额外奖励；
- 速度会随距离缓慢提升（有上限），撞上障碍即本次冲刺结束；
- 结束后结算：距离、能量币、最高速度与 S/A/B/C 评级，并记录本地最远纪录（存于浏览器 localStorage）。

## 部署

`dist/` 是可直接部署到任意静态 CDN / 虚拟主机的纯静态目录（仅 3 个文件，相对路径引用）：

```bash
# Vercel
vercel deploy dist --prod --yes

# Netlify
netlify deploy --prod --dir dist

# Cloudflare Pages
wrangler pages deploy dist --project-name neon-city-sprint

# 或任意对象存储 / Nginx：把 dist/ 目录整体上传即可
```

也可以 Fork 后用 GitHub Pages：把 `dist/` 内容推到 `gh-pages` 分支或 `/docs` 目录并开启 Pages。

## 可以继续优化的方向

1. **玩法**：加入磁铁 / 护盾 / 双倍得分等道具，滑铲动作与低空障碍，连击（combo）加成；
2. **场景**：雨夜反射、隧道段、高架桥段落、随距离渐变的多个城区主题（赛博核心区 → 工业港 → 郊环）；
3. **视觉**：WebGL/Canvas 光晕后期、镜头晃动与 FOV 随速度变化、障碍被撞飞的碎片动画；
4. **手感**：落地缓冲、擦边 near-miss 额外奖励、难度曲线细化、每日挑战种子；
5. **工程**：把实体池改成对象复用池、加入 Service Worker 离线缓存、成绩榜后端（如 Supabase）；
6. **音频**：背景合成器音乐随速度变调、程序化引擎音。
